The Post-Quantum channel of nymserv-ng eliminates the historical vulnerabilities of classic public-key algorithms (RSA and Elliptic Curves) against future quantum computers running Shor's algorithm, neutralizing passive Harvest Now, Decrypt Later dragnet surveillance.

Why ASCII Armored Text Format (pqpg) Instead of Raw Binary?
Raw binary files (.bin) are intended solely for cryptographic developers embedding low-level C or Rust libraries (native NIST FIPS 203).
For users, email messages, and network transport, nymserv-ng natively adopts the human-readable pqpg standard (ASCII Armor with -----BEGIN PQPG PUBLIC KEY----- and -----BEGIN PQPG MESSAGE-----). It behaves just like OpenPGP, but with unbreakable hybrid post-quantum cryptography.

2. Step-by-Step Guide for Beginners: Creating a Post-Quantum Nym

Step 1: Get the pqpg tool

Download the precompiled standalone binary for Linux x86_64, or install via Cargo: 

# Download standalone Linux x86_64 binary
curl -sO https://nymserv-ng.virebent.art/bin/pqpg-linux-amd64
chmod +x pqpg-linux-amd64
sudo mv pqpg-linux-amd64 /usr/local/bin/pqpg

# Or install from source via Rust/Cargo
cargo install pqpg

Step 2: Generate your Post-Quantum keypair

Create a dedicated directory and generate your personal identity with a single command: 

mkdir -p ~/Nym-pq && cd ~/Nym-pq
pqpg keygen

This automatically creates two text files:

  • identity.pub (Your public key: contains ML-KEM-768 encapsulation, X25519 DH, and Ed25519 signing keys).
  • identity.key (Your private secret key: store securely and never share!).

Step 3: Download the server's public key

curl -sO https://nymserv-ng.virebent.art/nymserver-pq-pubkey.asc

Step 4: Prepare the config.txt registration file

Create a text file named config.txt. Paste your Public-Key: block (the exact contents of your identity.pub) and define your Reply-Block:: 

Config:
From: youralias@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PQPG PUBLIC KEY-----
MCowBQYDK2VwAyEAX55L6Y57jT7J14e7aXF/zP3wD4gS12vYw6t9rP9oQkE=
... (paste the full contents of identity.pub here) ...
-----END PQPG PUBLIC KEY-----
Reply-Block:
::
Anon-To: your_real_email@secure-provider.org

Nym-Commands: +cryptrecv +pqsend
Understanding Reply-Blocks
The Reply-Block specifies the return routing used by the server to deliver incoming messages:
• Direct Delivery: As shown above with Anon-To: your_real_email@secure-provider.org, the server delivers encrypted mail directly to your inbox.
• Anonymous Multi-Hop Delivery (Mixnet): You can insert nested YAMN or Mixmaster encrypted reply blocks so that not even the nym server knows your true email or IP address.

Step 5: Encrypt the configuration packet with pqpg

Encrypt config.txt to the server's public key downloaded in Step 3: 

pqpg encrypt --recipient-key nymserver-pq-pubkey.asc config.txt > config.asc

The resulting config.asc is standard ASCII text beginning with -----BEGIN PQPG MESSAGE-----.

Step 6: Send the registration email

Send an email containing config.asc in the message body to:

config@nymserv-ng.virebent.art

The server decrypts the payload with its master ML-KEM key, registers the alias in the embedded ACID redb engine, and dispatches an encrypted post-quantum confirmation to your Reply-Block.

3. Receiving Post-Quantum Messages (Inbound)

When someone writes to your alias (e.g. youralias@nymserv-ng.virebent.art):

  1. The server encrypts the incoming message on the fly using your Post-Quantum public key (ML-KEM-768 + ChaCha20-Poly1305).
  2. The ciphertext packet -----BEGIN PQPG MESSAGE----- is delivered to your Reply-Block.
  3. To decrypt and read the message, save it as a file (e.g. message.eml) and decrypt with your private key: 
    pqpg decrypt --key identity.key message.eml

4. Sending Anonymous Mail (Outbound via send@)

To send clearnet email displaying your Post-Quantum alias as the sender:

  1. Prepare a text file outbound.txt with routing headers: 
    ::
Anon-To: recipient@example.com
Subject: Hello from the post-quantum future

This message is sent anonymously through my ML-KEM protected alias.
  2. Sign the file with your private key to authenticate ownership: 
    pqpg sign --key identity.key outbound.txt > outbound.signed
  3. Encrypt the signed message with the server's public key: 
    pqpg encrypt --recipient-key nymserver-pq-pubkey.asc outbound.signed > outbound.asc
  4. Send the resulting encrypted message to: 
    send@nymserv-ng.virebent.art

The server validates the cryptographic signature, appends the X-Nym-Disclaimer header, and delivers the email to the final recipient.
