Why Migrate to the Post-Quantum Channel?

While legacy OpenPGP remains fully supported for historical continuity, it presents architectural limitations that are no longer adequate for high-risk threat models:

Capability Legacy OpenPGP Post-Quantum Channel (NG)
Quantum Resistance Vulnerable to Shor's algorithm (RSA / ECC) Immune (NIST FIPS 203 ML-KEM-768)
Forward Secrecy (PFS) None (static keys: seizure compromises all past traffic) Perfect (ephemeral X25519 per message session)
Ciphertext Integrity Optional signatures / malleable packets Authenticated AEAD (ChaCha20-Poly1305)
Software Stack Heavy GnuPG, dirmngr/agent daemons, C libraries pqpg: standalone pure-Rust binary (1.2 MB)
Air-Gapped Operation Cumbersome (file transfer or USB drives) Native terminal QR Code projection

The Client: pqpg (Post-Quantum Privacy Guard)

To enable instant adoption of post-quantum cryptography without wrestling with complex toolchains, we provide pqpg, a standalone command-line cryptographic tool written entirely in pure Rust (memory-safe, zero buffer overflows, memory secured with mlock and zeroize).

Step-by-Step pqpg Quickstart

1. Generate Your Keypair

pqpg keygen -n mynym --qr

Generates your private key mynym.key (saved with 0600 permissions) and public key mynym.pub. The --qr flag displays a high-density QR Code in your terminal, allowing an air-gapped camera or smartphone to ingest the public key without any network attachment.

2. Encrypt a Message for a Recipient

pqpg encrypt -r recipient.pub message.txt -o message.msg

Or pipe directly from standard input with QR display:

echo "Classified brief" | pqpg encrypt -r recipient.pub --qr

3. Decrypt Received Mail

pqpg decrypt -s mynym.key message.msg

4. Digital Signatures and Verification (Ed25519)

# Sign a document (outputs a 64-byte detached signature)
pqpg sign -s mynym.key document.pdf -o document.sig

# Verify signature against author's public key
pqpg verify -k author.pub -s document.sig document.pdf

5. Air-Gapped Terminal QR Projection

pqpg qr any_file.txt
