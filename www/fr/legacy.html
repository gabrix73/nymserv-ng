Le canal classique de nymserv-ng est 100% compatible avec le standard historique crooks/ghionym (nymserver.pl). Toutes les opérations (aide, clés, enregistrement d'alias, lecture et envoi) peuvent être effectuées entièrement par courrier électronique, sans utiliser de navigateur web.

Qu'est-ce qu'un Nymserver en termes simples ?
Un nymserver vous fournit une adresse e-mail pseudonyme permanente (ex. votrealias@nymserv-ng.virebent.art).
Lorsque quelqu'un vous écrit à cette adresse, le serveur chiffre le message avec votre clé PGP et le transmet à votre boîte aux lettres réelle ou via une chaîne de remailers anonymes (Reply-Block). Vos correspondants ne connaissent jamais votre identité ni votre adresse réelle, et votre fournisseur d'e-mail ne voit que des messages chiffrés venant du nymserver.

1. Commandes E-mail (Interaction Automatisée sans Navigateur)

Vous pouvez envoyer un e-mail ordinaire vers les adresses automatisées suivantes du serveur :

help@nymserv-ng.virebent.art
(ou info@)		 Indifférent (même vide) Renvoie immédiatement le document d'aide complet avec la syntaxe de toutes les commandes.
key@nymserv-ng.virebent.art
(ou remailer-key@)		 Indifférent (même vide) Renvoie les clés publiques officielles du serveur (OpenPGP ASCII Armor et Post-Quantique ML-KEM-768).

2. Guide Pas à Pas pour Débutants : Création de votre Alias

Étape 1 : Générez votre paire de clés GnuPG pour votre pseudonyme

Ouvrez un terminal sur votre machine et générez une nouvelle clé dédiée à votre pseudonyme :

gpg --batch --passphrase '' --quick-generate-key "votrealias <votrealias@nymserv-ng.virebent.art>" rsa4096 default 0

Note : Remplacez votrealias par le nom de votre choix.

Étape 2 : Exportez votre clé publique au format texte armuré

gpg --armor --export votrealias > mykey.asc

Étape 3 : Téléchargez et importez la clé publique de 2 novembre

Téléchargez-la sur le site web ou demandez-la par e-mail à key@nymserv-ng.virebent.art :

curl -s https://nymserv-ng.virebent.art/nymserver-openpgp.asc | gpg --import

Vérifiez que l'identifiant de clé importé est : D455E394E202E5CC

Étape 4 : Préparez le fichier de configuration (config.txt)

Créez un fichier texte nommé config.txt avec la structure exacte suivante :

Config:
From: votrealias@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PGP PUBLIC KEY BLOCK-----
[COLLEZ ICI LE CONTENU EXACT DE mykey.asc]
-----END PGP PUBLIC KEY BLOCK-----
Reply-Block:
::
Anon-To: votre_vraie_adresse@fournisseur-securise.org

Nym-Commands: +cryptrecv +sigsend
Comment fonctionne le Reply-Block ?
Le Reply-Block indique au serveur où acheminer les courriels reçus pour votre alias.
  • Mode Direct (Simple pour débutants) : Avec Anon-To: votre_vraie_adresse@..., le serveur transfère directement à votre boîte réelle. Aucun correspondant externe ne voit jamais votre vraie adresse. Tous les courriels reçus arrivent chiffrés avec votre clé PGP.
  • Chaîne de Remailers Anonymes (Avancé) : Si vous ne souhaitez pas que le serveur connaisse votre boîte de réception finale, créez un bloc chiffré en oignon multi-sauts (ex. avec yamn -r ou mixmaster).

Étape 5 : Chiffrez config.txt avec la clé du serveur

Chiffrez le fichier à destination de la clé publique du serveur :

gpg --armor --recipient 0xD455E394E202E5CC --encrypt config.txt

Ce fichier produit config.txt.asc.

Étape 6 : Envoyez la configuration à config@

Envoyez le contenu de config.txt.asc à :

config@nymserv-ng.virebent.art

Vous pouvez l'expédier depuis votre client de messagerie habituel ou depuis un terminal :

mail -s "Config request" config@nymserv-ng.virebent.art < config.txt.asc

Le serveur enregistre l'alias et vous envoie une confirmation chiffrée à votre Reply-Block.

3. Comment Recevoir et Lire le Courrier (Entrant)

  1. Donnez votre adresse pseudonyme à vos contacts : votrealias@nymserv-ng.virebent.art.
  2. Lorsque quelqu'un vous écrit, nymserv-ng chiffre le contenu avec votre clé PGP et le transmet à la destination de votre Reply-Block.
  3. Dans votre boîte aux lettres réelle, vous recevez un message chiffré contenant -----BEGIN PGP MESSAGE-----.
  4. Pour le lire, enregistrez-le sous msg.asc et déchiffrez-le avec GPG : 
    gpg --decrypt msg.asc

4. Comment Envoyer un Courriel Anonyme (Sortant via send@)

Pour expédier un e-mail sur le clearnet avec votre alias comme expéditeur :

  1. Créez un fichier texte avec vos en-têtes et le corps du message : 
    From: votrealias@nymserv-ng.virebent.art
To: ami@destinataire.com
Subject: Message confidentiel

Bonjour, ce message a été envoyé anonymement via nymserv-ng.
  2. Signez le fichier avec votre clé privée et chiffrez-le pour le serveur (0xD455E394E202E5CC) : 
    gpg --sign --armor --default-key votrealias message.txt
gpg --armor --recipient 0xD455E394E202E5CC --encrypt message.txt.asc
  3. Envoyez le résultat chiffré à :
    send@nymserv-ng.virebent.art
  4. Le serveur valide votre signature numérique, supprime les traces de relais locales, appose l'avertissement et transmet le courriel à ami@destinataire.com.

5. Modification ou Suppression de l'Alias

  • Mettre à jour le Reply-Block : Envoyez un nouveau message Config: signé avec le nouveau Reply-Block:.
  • Désactiver temporairement l'alias : Envoyez un message Config: contenant Nym-Commands: +disable.
  • Supprimer définitivement l'alias : Envoyez un message Config: signé avec Nym-Commands: delete.
