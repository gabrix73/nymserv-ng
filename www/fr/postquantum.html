Pourquoi Migrer vers le Canal Post-Quantique ?

Bien que le protocole historique OpenPGP demeure opérationnel pour assurer la continuité d'usage, il présente des faiblesses architecturales majeures pour la confidentialité à haut risque :

Fonctionnalité OpenPGP Historique Canal Post-Quantique (NG)
Résistance Quantique Vulnérable à Shor (RSA / Courbes Elliptiques) Immunisé (NIST FIPS 203 ML-KEM-768)
Confidentialité Persistante (PFS) Absente (clé statique : la saisie compromet tout le passé) Parfaite (clés éphémères X25519 par session de message)
Intégrité du Chiffré Signature facultative / paquets malléables AEAD Authentifié (ChaCha20-Poly1305)
Dépendances Logicielles GnuPG lourd, démons dirmngr/agent, bibliothèques C pqpg : binaire autonome en Rust pur (1,2 Mo)
Opérations Isolées (Air-Gap) Complexes (transfert de fichiers ou clés USB) Affichage QR Code natif dans le terminal

Le Client : pqpg (Post-Quantum Privacy Guard)

Pour permettre l'adoption immédiate du canal post-quantique sans dépendre d'environnements cryptographiques lourds, nous mettons à disposition pqpg, un utilitaire en ligne de commande autonome écrit intégralement en Rust pur (sécurité mémoire native, absence de débordement de tampon, mémoire protégée par mlock et zeroize).

Guide Pratique Pas-à-Pas avec pqpg

1. Génération de votre paire de clés

pqpg keygen -n mynym --qr

Génère la clé privée mynym.key (droits 0600) et la clé publique mynym.pub. L'option --qr affiche un QR Code haute densité dans le terminal pour permettre à une caméra ou un appareil isolé de lire la clé sans connexion réseau.

2. Chiffrement d'un message pour un destinataire

pqpg encrypt -r recipient.pub message.txt -o message.msg

Ou directement depuis l'entrée standard avec projection QR :

echo "Note confidentielle" | pqpg encrypt -r recipient.pub --qr

3. Déchiffrement du courrier reçu

pqpg decrypt -s mynym.key message.msg

4. Signature numérique et vérification (Ed25519)

# Signature d'un fichier (génère une signature détachée de 64 octets)
pqpg sign -s mynym.key document.pdf -o document.sig

# Vérification avec la clé publique de l'auteur
pqpg verify -k author.pub -s document.sig document.pdf

5. Affichage QR Code pour Machine Isolée (Air-Gap)

pqpg qr tout_fichier.txt
