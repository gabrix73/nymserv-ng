Le canal Post-Quantique de nymserv-ng élimine les vulnérabilités historiques des algorithmes à clé publique classiques (RSA et Courbes Elliptiques) face aux ordinateurs quantiques et aux attaques de surveillance passive Harvest Now, Decrypt Later.

Pourquoi le Format Texte ASCII Armored (pqpg) et Non le Binaire Brut ?
Les fichiers binaires bruts (.bin) sont réservés aux développeurs cryptographiques intégrant des bibliothèques C ou Rust à bas niveau.
Pour les utilisateurs et les échanges d'emails, nymserv-ng supporte nativement le standard pqpg en texte lisible (ASCII Armor avec en-têtes -----BEGIN PQPG PUBLIC KEY----- et -----BEGIN PQPG MESSAGE-----). C'est aussi simple qu'OpenPGP, mais avec un chiffrement hybride post-quantique inviolable.

Vous pouvez télécharger la clé publique au format texte directement sur le web ou la recevoir par email :

  • Par Email Automatique : Envoyez un email vide à key@nymserv-ng.virebent.art. Le serveur répondra immédiatement avec le bloc complet BEGIN PQPG PUBLIC KEY.

2. Guide Pas à Pas pour Débutants : Créer Votre Nym Post-Quantique

Étape 1 : Obtenir l'outil pqpg

Téléchargez le binaire autonome pour Linux x86_64, ou installez-le avec Cargo : 

# Téléchargement du binaire Linux x86_64
curl -sO https://nymserv-ng.virebent.art/bin/pqpg-linux-amd64
chmod +x pqpg-linux-amd64
sudo mv pqpg-linux-amd64 /usr/local/bin/pqpg

# Ou installation depuis les sources Rust/Cargo
cargo install pqpg

Étape 2 : Générer votre paire de clés Post-Quantiques

mkdir -p ~/Nym-pq && cd ~/Nym-pq
pqpg keygen

Cette commande crée deux fichiers texte :

  • identity.pub (Votre clé publique : encapsulation ML-KEM-768, échange X25519 et signature Ed25519).
  • identity.key (Votre clé privée secrète : conservez-la précieusement et ne la partagez jamais !).

Étape 3 : Télécharger la clé publique du serveur

curl -sO https://nymserv-ng.virebent.art/nymserver-pq-pubkey.asc

Étape 4 : Préparer le fichier de configuration config.txt

Créez un fichier texte nommé config.txt avec votre bloc Public-Key: (le contenu complet de identity.pub) et votre Reply-Block: : 

Config:
From: votrealias@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PQPG PUBLIC KEY-----
MCowBQYDK2VwAyEAX55L6Y57jT7J14e7aXF/zP3wD4gS12vYw6t9rP9oQkE=
... (collez ici le contenu complet de identity.pub) ...
-----END PQPG PUBLIC KEY-----
Reply-Block:
::
Anon-To: votre_vrai_email@fournisseur-securise.org

Nym-Commands: +cryptrecv +pqsend

Étape 5 : Chiffrer le paquet d'inscription avec pqpg

Chiffrez le fichier config.txt avec la clé publique du serveur : 

pqpg encrypt --recipient-key nymserver-pq-pubkey.asc config.txt > config.asc

Étape 6 : Envoyer la demande à config@

Envoyez un email contenant le bloc config.asc à :

config@nymserv-ng.virebent.art

Le serveur déchiffre la charge utile avec sa clé maîtresse ML-KEM, enregistre votre alias dans la base ACID redb et vous envoie une confirmation chiffrée.

3. Réception des Messages Post-Quantiques (Inbound)

Lorsque quelqu'un écrit à votrealias@nymserv-ng.virebent.art :

  1. Le serveur chiffre l'email à la volée avec votre clé publique Post-Quantique (ML-KEM-768 + ChaCha20-Poly1305).
  2. Le message chiffré -----BEGIN PQPG MESSAGE----- est remis à votre Reply-Block.
  3. Pour lire le message reçu, enregistrez-le (par ex. message.eml) et déchiffrez-le avec votre clé secrète : 
    pqpg decrypt --key identity.key message.eml

4. Envoi d'Emails Anonymes (Outbound via send@)

Pour envoyer des emails vers l'Internet public depuis votre alias :

  1. Préparez le fichier envoi.txt : 
    ::
Anon-To: destinataire@example.com
Subject: Message sécurisé post-quantique

Corps de votre message anonyme...
  2. Signez le fichier avec votre clé privée : 
    pqpg sign --key identity.key envoi.txt > envoi.signed
  3. Chiffrez le fichier signé pour le serveur : 
    pqpg encrypt --recipient-key nymserver-pq-pubkey.asc envoi.signed > envoi.asc
  4. Envoyez le résultat à : 
    send@nymserv-ng.virebent.art
