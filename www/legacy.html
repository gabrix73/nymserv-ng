The legacy channel of nymserv-ng is 100% bit-level compatible with the historical crooks/ghionym standard (nymserver.pl). All operations (help docs, public keys, alias registration, inbound reading, and outbound sending) can be conducted completely over email without opening a web browser.

What is a Nymserver in Plain English?
A nymserver provides you with a persistent, anonymous pseudonym email address (e.g. youralias@nymserv-ng.virebent.art).
When someone emails your alias, the server encrypts the message with your PGP public key and forwards it to your real mailbox or through an onion chain of anonymous remailers (Reply-Block). Correspondents never know who or where you are; and your email provider only sees incoming encrypted PGP blobs from the nymserver.

2. Step-by-Step Guide for Beginners: Creating Your Alias

Step 1: Generate your pseudonym GnuPG keypair

Open a terminal on your computer and generate a key dedicated to your new pseudonym:

gpg --batch --passphrase '' --quick-generate-key "youralias <youralias@nymserv-ng.virebent.art>" rsa4096 default 0

Note: Replace youralias with your chosen name. You may add a passphrase by removing --passphrase ''.

Step 2: Export your public key in text armor format

gpg --armor --export youralias > mykey.asc

Step 3: Import the 2 novembre server public key

Download it from the site or request it by sending an email to key@nymserv-ng.virebent.art:

curl -s https://nymserv-ng.virebent.art/nymserver-openpgp.asc | gpg --import

Verify that the imported Key ID is: D455E394E202E5CC

Step 4: Prepare the configuration file (config.txt)

Create a text file named config.txt with the following exact layout:

Config:
From: youralias@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PGP PUBLIC KEY BLOCK-----
[PASTE HERE THE ENTIRE CONTENT OF mykey.asc]
-----END PGP PUBLIC KEY BLOCK-----
Reply-Block:
::
Anon-To: your_real_email@secure-provider.org

Nym-Commands: +cryptrecv +sigsend
How Does the Reply-Block Work?
The Reply-Block instructs the nymserver where to forward messages received for your alias.
  • Direct Delivery Mode (Beginner friendly): Using Anon-To: your_real_email@secure-provider.org, the server forwards directly to your real mailbox. External correspondents never see your real address because they only address youralias@nymserv-ng.virebent.art. All forwarded mail arrives encrypted with your PGP key.
  • Anonymous Remailer Chain (Advanced): If you do not want the nymserver operator to know your destination mailbox, generate an onion-encrypted multi-hop remailer block (e.g. using yamn -r or mixmaster).

Step 5: Encrypt config.txt with the server's public key

Encrypt the configuration file to the server's key:

gpg --armor --recipient 0xD455E394E202E5CC --encrypt config.txt

This creates the encrypted file config.txt.asc.

Step 6: Send the configuration to config@

Send the content of config.txt.asc to:

config@nymserv-ng.virebent.art

You can send this via your normal email client (pasting the armored block in the body) or from terminal:

mail -s "Config request" config@nymserv-ng.virebent.art < config.txt.asc

The server parses the registration and dispatches an encrypted confirmation message to your Reply-Block.

3. How to Receive and Read Incoming Email (Inbound)

  1. Give out your pseudonym address to anyone: youralias@nymserv-ng.virebent.art.
  2. When someone sends you an email, nymserv-ng receives it, encrypts it with your PGP public key (via +cryptrecv), attaches your Reply-Block, and delivers it to your destination mailbox.
  3. In your real inbox, you will receive an encrypted message containing -----BEGIN PGP MESSAGE-----.
  4. Save it as msg.asc and decrypt it with your private key: 
    gpg --decrypt msg.asc

4. How to Send Email from Your Alias (Outbound via send@)

To send a clearnet email displaying your alias as the sender:

  1. Create a text file with the message and target headers: 
    From: youralias@nymserv-ng.virebent.art
To: friend@destination.com
Subject: Encrypted greeting

Hello, this message was sent anonymously through nymserv-ng.
  2. Sign the message with your alias key and encrypt it to the server key (0xD455E394E202E5CC): 
    gpg --sign --armor --default-key youralias message.txt
gpg --armor --recipient 0xD455E394E202E5CC --encrypt message.txt.asc
  3. Send the resulting encrypted payload to:
    send@nymserv-ng.virebent.art
  4. The server verifies your cryptographic signature, removes local relay traces, appends the anonymous disclaimer, and delivers the message to friend@destination.com.

5. Updating or Deleting Your Pseudonym

  • Update Reply-Block: Send a new signed Config: message with the updated Reply-Block:.
  • Temporarily Disable Alias: Send a Config: message containing Nym-Commands: +disable.
  • Permanently Delete Alias: Send a signed Config: message containing Nym-Commands: delete.
