The legacy channel of nymserv-ng maintains 100% bit-level backward compatibility with the historic crooks/ghionym (nymserver.pl) standard. If you use existing remailer scripts, GnuPG (gpg), Mixmaster, or YAMN, you can register and operate your pseudonym without any changes to your client setup.

1. How to Register an Alias (Config)

Compose a plain text file containing a standard Config: block, encrypt it with the server's OpenPGP public key (Key ID: D455E394E202E5CC), and transmit it (ideally through YAMN remailers) to:
config@nymserv-ng.virebent.art 

Config:
From: youralias@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PGP PUBLIC KEY BLOCK-----
... your PGP public key block ...
-----END PGP PUBLIC KEY BLOCK-----
Reply-Block:
::
Anon-To: your_real_mailbox@destination.org
... Mixmaster / Remailer onion routing chain ...

Nym-Commands: +cryptrecv +acksend +sigsend

Supported Configuration Flags

  • +cryptrecv: Encrypts all incoming clearnet emails with your public key prior to remailer delivery (enabled by default, strongly recommended).
  • +sigsend: Enforces a valid PGP digital signature on all outbound messages sent under your alias.
  • +acksend: Dispatches an encrypted receipt notification to your Reply-Block whenever an outbound email is processed.
  • +fixedsz: Pads outbound messages to fixed size increments to frustrate packet length correlation attacks.

2. Sending Email via Your Alias (Send)

To send a clearnet email under your pseudonymous identity, compose the message, sign it with your PGP private key, encrypt it to the server's OpenPGP key, and send it to:
send@nymserv-ng.virebent.art 

From: youralias@nymserv-ng.virebent.art
To: recipient@any-provider.org
Subject: Greetings from the mixnet

This message was routed and delivered anonymously via nymserv-ng.
