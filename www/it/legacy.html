Il canale legacy di nymserv-ng è compatibile al 100% con lo standard storico crooks/ghionym (nymserver.pl). Tutte le operazioni (richiesta guide, chiavi, registrazione alias, ricezione e invio email) possono essere svolte interamente via email, senza mai aprire un browser web.

Cos'è un Nymserver in parole semplici?
Un nymserver ti fornisce un indirizzo email pseudonimo permanente (es. tuoalias@nymserv-ng.virebent.art).
Quando qualcuno ti scrive a questo indirizzo, il server cifra il messaggio con la tua chiave PGP e lo inoltra alla tua vera casella di posta o attraverso una catena di remailer anonimi (Reply-Block). Chi ti scrive non sa chi sei né dove ti trovi; e il fornitore della tua casella reale vede solo messaggi cifrati provenienti dal nymserver.

1. Comandi via Email (Interazione Automatica Senza Browser)

Puoi inviare una normale email (anche dal tuo client di posta preferito o via terminale) ai seguenti indirizzi automatici del server:

Indirizzo Destinatario Oggetto / Contenuto Risposta del Server
help@nymserv-ng.virebent.art
(o info@)		 Qualsiasi (anche vuoto) Invia via email il documento di aiuto completo con la sintassi di tutti i comandi.
key@nymserv-ng.virebent.art
(o remailer-key@)		 Qualsiasi (anche vuoto) Restituisce le chiavi pubbliche ufficiali del server (OpenPGP ASCII Armor e Post-Quantum ML-KEM-768).
key@nymserv-ng.virebent.art Oggetto o corpo:
get <nomealias>		 Cerca l'alias specificato nel database e ti risponde con il suo blocco di chiave pubblica PGP.
finger@nymserv-ng.virebent.art Oggetto o corpo:
<nomealias>		 Equivalente a key@ con get: estrae la chiave pubblica dell'alias richiesto.
list@nymserv-ng.virebent.art
(o used@)		 Qualsiasi (anche vuoto) Restituisce l'elenco aggiornato di tutti gli pseudonimi attualmente registrati e occupati.
nobody@nymserv-ng.virebent.art Qualsiasi Scarta silenziosamente il messaggio senza rimbalzo o risposta (blackhole / test di consegna MTA).
config@nymserv-ng.virebent.art Blocco Config: cifrato Registra, aggiorna o cancella il tuo pseudonimo. Invia conferma cifrata al tuo Reply-Block.
send@nymserv-ng.virebent.art Messaggio cifrato e firmato Rimuove gli header identificativi, appone il disclaimer e invia l'email nel clearnet a nome del tuo alias.

2. Guida Passo-Passo per Principianti: Creazione del tuo Alias

Passo 1: Genera la tua coppia di chiavi GnuPG

Apri un terminale sul tuo computer e genera una nuova chiave dedicata al tuo pseudonimo:

gpg --batch --passphrase '' --quick-generate-key "tuoalias <tuoalias@nymserv-ng.virebent.art>" rsa4096 default 0

Nota: Sostituisci tuoalias con il nome pseudonimo che desideri. Puoi impostare una passphrase se lo desideri rimuovendo --passphrase ''.

Passo 2: Esporta la tua chiave pubblica in formato testo

gpg --armor --export tuoalias > mykey.asc

Passo 3: Scarica e importa la chiave pubblica di 2 novembre

Puoi scaricarla dal sito web o richiederla via email a key@nymserv-ng.virebent.art:

curl -s https://nymserv-ng.virebent.art/nymserver-openpgp.asc | gpg --import

Verifica che l'ID chiave importato sia: D455E394E202E5CC

Passo 4: Prepara il file di configurazione (config.txt)

Crea un file di testo chiamato config.txt con la seguente struttura:

Config:
From: tuoalias@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PGP PUBLIC KEY BLOCK-----
[INCOLLA QUI IL CONTENUTO ESATTO DI mykey.asc]
-----END PGP PUBLIC KEY BLOCK-----
Reply-Block:
::
Anon-To: la_tua_vera_email@provider-sicuro.org

Nym-Commands: +cryptrecv +sigsend
Come funziona il Reply-Block?
Il Reply-Block dice al server dove mandare la posta che arriva per il tuo alias.
  • Modalità Diretta (Semplice): Usando Anon-To: la_tua_vera_email@provider-sicuro.org, il server invia direttamente alla tua casella reale. Nessun mittente esterno vedrà mai la tua email reale perché chi scrive vede solo tuoalias@nymserv-ng.virebent.art. Tutti i messaggi in arrivo ti arriveranno cifrati con la tua chiave PGP.
  • Modalità Anonima Avanzata (Mixmaster / YAMN): Se non vuoi che nemmeno il gestore del server conosca la tua casella reale, puoi inserire una catena a cipolla crittografica cifrata su più nodi remailer (es. yamn -r ...).

Passo 5: Cifra config.txt con la chiave del server

Cifra il file appena creato indirizzandolo alla chiave del server:

gpg --armor --recipient 0xD455E394E202E5CC --encrypt config.txt

Questo comando produrrà il file cifrato config.txt.asc.

Passo 6: Spedisci la configurazione a config@

Invia il contenuto del file config.txt.asc a:

config@nymserv-ng.virebent.art

Puoi spedirlo tramite il tuo normale client di posta (incollando il testo cifrato nel corpo del messaggio), oppure da terminale con:

mail -s "Config request" config@nymserv-ng.virebent.art < config.txt.asc

Il server elaborerà la registrazione e invierà una conferma cifrata al tuo indirizzo di Reply-Block.

3. Come Ricevere e Leggere la Posta (Inbound)

  1. Comunica il tuo indirizzo pseudonimo a chi vuoi: tuoalias@nymserv-ng.virebent.art.
  2. Quando qualcuno ti spedisce un'email, nymserv-ng la riceve, la cifra con la tua chiave pubblica PGP (grazie a +cryptrecv) e la recapita alla destinazione indicata nel tuo Reply-Block.
  3. Nella tua casella postale reale troverai un messaggio con un blocco cifrato -----BEGIN PGP MESSAGE-----.
  4. Per leggerlo, salvalo come messaggio.asc e decifralo con GPG: 
    gpg --decrypt messaggio.asc

4. Come Inviare Email dal tuo Alias (Outbound via send@)

Per inviare un'email nel clearnet mostrando come mittente il tuo alias pseudonimo:

  1. Crea un file di testo con il messaggio e gli header di destinazione: 
    From: tuoalias@nymserv-ng.virebent.art
To: amico@destinazione.com
Subject: Messaggio riservato

Ciao, ti scrivo dal mio indirizzo pseudonimo protetto da nymserv-ng.
  2. Firma il messaggio con la tua chiave privata PGP e poi cifralo con la chiave del server (0xD455E394E202E5CC): 
    gpg --sign --armor --default-key tuoalias messaggio.txt
gpg --armor --recipient 0xD455E394E202E5CC --encrypt messaggio.txt.asc
  3. Invia il pacchetto cifrato risultante a:
    send@nymserv-ng.virebent.art
  4. Il server decifrerà la busta, verificherà la tua firma digitale, aggiungerà il disclaimer anonimo e consegnerà l'email a amico@destinazione.com.

5. Modifica o Cancellazione dell'Alias

  • Aggiornare il Reply-Block: Invia un nuovo messaggio Config: firmato con la tua chiave PGP contenente il nuovo blocco Reply-Block:.
  • Disabilitare temporaneamente l'alias: Invia un comando Config: con la direttiva Nym-Commands: +disable.
  • Cancellare definitivamente l'alias: Invia un comando Config: firmato contenente Nym-Commands: delete.
