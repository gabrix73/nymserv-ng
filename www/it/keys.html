2. Chiave Master Post-Quantica (Canale Moderno • NIST FIPS 203 ML-KEM / pqpg)

Utilizzata per l'incapsulamento crittografico resistente ai futuri computer quantistici (immunità contro attacchi Harvest Now, Decrypt Later). Formato testo ASCII Armor compatibile direttamente con pqpg.

=> Scarica Chiave Testo ASCII Armor: nymserver-pq-pubkey.asc
=> Scarica Chiave Grezza Binaria (1.184 byte raw): nymserver-pq-pubkey.bin

  • Algoritmi Ibridi: NIST FIPS 203 ML-KEM-768 + X25519 (DH) + Ed25519 (Firme)
