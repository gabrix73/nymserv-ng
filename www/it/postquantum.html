Perché il Passaggio al Canale Post-Quantum?

Sebbene il protocollo legacy OpenPGP rimanga pienamente operativo per continuità storica, soffre di limiti architetturali non più accettabili per la riservatezza ad alto rischio:

Caratteristica Legacy OpenPGP Canale Post-Quantico (NG)
Resistenza Quantistica Vulnerabile a Shor (RSA / Curve Ellittiche) Immune (NIST FIPS 203 ML-KEM-768)
Forward Secrecy (PFS) Assente (chiave statica: la confisca decifra tutto il passato) Perfetta (chiavi effimere X25519 generate per ogni messaggio)
Integrità Ciphertext Firma opzionale / pacchetti malleabili AEAD Autenticato (ChaCha20-Poly1305)
Dipendenze Software GnuPG pesante, demoni dirmngr/agent, librerie C pqpg: binario unico in puro Rust (1.2 MB)
Operatività Air-Gapped Complicata (richiede esportazione file o chiavette USB) Supporto nativo QR Code a terminale

Il Client: pqpg (Post-Quantum Privacy Guard)

Per consentire l'utilizzo immediato del canale post-quantico senza dover configurare librerie crittografiche complesse, forniamo pqpg, un'utility standalone per riga di comando scritta interamente in puro Rust (memory-safe, zero buffer overflow, memoria protetta con mlock e zeroize).

Download Diretto Eseguibile (Linux x86_64 Standalone, 1.2 MB)

Guida Passo-Passo all'Utilizzo di pqpg

1. Generazione della propria coppia di chiavi

pqpg keygen -n mynym --qr

Genera la chiave privata mynym.key (salvata automaticamente con permessi 0600) e la chiave pubblica mynym.pub. Il flag --qr proietta a video nel terminale il QR Code della chiave pubblica per scansionarla direttamente con uno smartphone o una webcam senza rete.

2. Cifratura di un messaggio per un destinatario

pqpg encrypt -r destinatario.pub messaggio.txt -o messaggio.msg

Oppure cifra direttamente da standard input con proiezione QR Code:

echo "Testo riservato" | pqpg encrypt -r destinatario.pub --qr

3. Decifratura della posta ricevuta

pqpg decrypt -s mynym.key messaggio.msg

4. Firma digitale e verifica (Ed25519)

# Firma di un documento (genera una firma detached di 64 byte)
pqpg sign -s mynym.key documento.pdf -o documento.sig

# Verifica della firma con la chiave pubblica dell'autore
pqpg verify -k autore.pub -s documento.sig documento.pdf

5. Visualizzazione QR Code Air-Gapped

pqpg qr qualsiasi_file.txt
