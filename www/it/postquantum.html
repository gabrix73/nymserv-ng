Il canale Post-Quantico di nymserv-ng è progettato per eliminare la vulnerabilità storica degli algoritmi a chiave pubblica tradizionali (RSA ed Curve Ellittiche) rispetto all'avvento dei computer quantistici (algoritmo di Shor e scenari di intercettazione passiva Harvest Now, Decrypt Later).

Perché il Formato Testo ASCII Armor (pqpg) e Non il File Binario?
I file binari grezzi (.bin) sono destinati esclusivamente agli sviluppatori crittografici che integrano librerie a basso livello in C o Rust (NIST FIPS 203 nativo).
Per gli utenti, le email e le comunicazioni via rete, nymserv-ng supporta pienamente lo standard pqpg in formato testo leggibile (ASCII Armor con intestazioni -----BEGIN PQPG PUBLIC KEY----- e -----BEGIN PQPG MESSAGE-----). È esattamente come OpenPGP, ma con cifratura ibrida post-quantica indistruttibile.

Puoi scaricare la chiave pubblica in formato testo ASCII Armor direttamente dal web o richiederla via email:

2. Guida Passo-Passo per Principianti: Creazione del tuo Nym Post-Quantico

Passo 1: Ottieni lo strumento pqpg

Scarica il binario standalone già compilato per Linux x86_64, oppure compila da sorgente tramite Cargo: 

# Download binario standalone Linux x86_64
curl -sO https://nymserv-ng.virebent.art/bin/pqpg-linux-amd64
chmod +x pqpg-linux-amd64
sudo mv pqpg-linux-amd64 /usr/local/bin/pqpg

# Oppure compilazione da sorgente con Rust/Cargo
cargo install pqpg

Passo 2: Genera la tua coppia di chiavi Post-Quantiche

Crea la tua cartella sicura e genera la tua identità post-quantica personale con un solo comando: 

mkdir -p ~/Nym-pq && cd ~/Nym-pq
pqpg keygen

Verranno generati automaticamente due file in formato testo:

  • identity.pub (La tua chiave pubblica: contiene la chiave di incapsulamento ML-KEM-768, la chiave X25519 e la chiave di firma Ed25519).
  • identity.key (La tua chiave privata segreta: custodiscila con massima cura e non condividerla mai!).

Passo 3: Scarica la chiave pubblica del server

curl -sO https://nymserv-ng.virebent.art/nymserver-pq-pubkey.asc

Passo 4: Prepara il file di configurazione config.txt

Crea un file di testo chiamato config.txt. Incolla all'interno il blocco Public-Key: (il contenuto esatto del tuo identity.pub) e definisci il tuo Reply-Block: per ricevere le risposte: 

Config:
From: rasmus73@nymserv-ng.virebent.art
Public-Key:
-----BEGIN PQPG PUBLIC KEY-----
MCowBQYDK2VwAyEAX55L6Y57jT7J14e7aXF/zP3wD4gS12vYw6t9rP9oQkE=
... (incolla qui tutto il contenuto del tuo identity.pub) ...
-----END PQPG PUBLIC KEY-----
Reply-Block:
::
Anon-To: la_tua_vera_email@provider-sicuro.org

Nym-Commands: +cryptrecv +pqsend
Come Funziona il Reply-Block?
Il Reply-Block è il percorso di instradamento inverso usato dal server per recapitarti le email in arrivo:
• Consegna Diretta: Come mostrato sopra con Anon-To: la_tua_vera_email@provider-sicuro.org, il server invia direttamente la posta cifrata alla tua casella.
• Consegna Anonima Multi-Hop (Mixnet): Puoi inserire blocchi di risposta cifrati YAMN o Mixmaster per ricevere posta senza che nemmeno il server conosca la tua reale casella email o il tuo indirizzo IP.

Passo 5: Cifra il pacchetto di configurazione con pqpg

Cifra il file config.txt usando la chiave pubblica del server scaricata al Passo 3: 

pqpg encrypt --recipient-key nymserver-pq-pubkey.asc config.txt > config.asc

Il file config.asc risultante sarà un blocco di testo standard che inizia con -----BEGIN PQPG MESSAGE-----.

Passo 6: Spedisci la registrazione via email

Invia un'email con il contenuto di config.asc nel corpo del messaggio a:

config@nymserv-ng.virebent.art

Il server decifrerà il messaggio usando la sua chiave master ML-KEM, registrerà il tuo alias nel database embedded redb e invierà una conferma cifrata Post-Quantica al tuo Reply-Block.

3. Ricezione Messaggi Post-Quantici (Inbound)

Quando qualcuno scrive al tuo alias (es. rasmus73@nymserv-ng.virebent.art):

  1. Il server riceve l'email e la cifra al volo utilizzando la tua chiave pubblica Post-Quantica (ML-KEM-768 + ChaCha20-Poly1305).
  2. Il messaggio cifrato -----BEGIN PQPG MESSAGE----- viene recapitato al tuo Reply-Block.
  3. Per leggere il messaggio ricevuto, salvalo in un file (es. messaggio.eml) e decifralo con la tua chiave privata: 
    pqpg decrypt --key identity.key messaggio.eml

4. Invio di Email Anonime dal tuo Alias (Outbound via send@)

Per spedire email verso qualsiasi destinatario clearnet mostrandoti con il tuo alias Post-Quantico:

  1. Prepara un file di testo invio.txt con gli header di instradamento: 
    ::
Anon-To: destinatario_finale@example.com
Subject: Saluti dal futuro post-quantico

Questo messaggio è inviato dal mio alias anonimo protetto da ML-KEM.
  2. Firma il file con la tua chiave privata per autenticare che l'alias appartiene a te: 
    pqpg sign --key identity.key invio.txt > invio.signed
  3. Cifra il messaggio firmato con la chiave pubblica del server: 
    pqpg encrypt --recipient-key nymserver-pq-pubkey.asc invio.signed > invio.asc
  4. Invia il messaggio risultante a: 
    send@nymserv-ng.virebent.art

Il server verificherà la firma crittografica della tua identità, apporrà l'header di disclaimer X-Nym-Disclaimer e consegnerà l'email al destinatario finale.
