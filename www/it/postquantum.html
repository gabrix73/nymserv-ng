Il canale Post-Quantico di nymserv-ng è progettato per eliminare la vulnerabilità storica degli algoritmi a chiave pubblica tradizionali (RSA ed Curve Ellittiche) rispetto all'avvento dei computer quantistici (algoritmo di Shor e scenari di intercettazione passiva Harvest Now, Decrypt Later).

Perché il Canale Post-Quantico per Principianti?
Le email cifrate oggi con RSA o PGP tradizionale possono essere archiviate da agenzie di sorveglianza per essere decifrate tra qualche anno quando saranno disponibili computer quantistici sufficientemente potenti.
Il canale Post-Quantico protegge le tue comunicazioni anonime con lo standard ufficiale NIST FIPS 203 (ML-KEM-768 / Kyber), garantendo che i tuoi messaggi rimangano indecifrabili per sempre.

1. Come Ottenere la Chiave Pubblica Post-Quantica del Server

Puoi scaricare la chiave pubblica ML-KEM-768 direttamente via web o richiederla automaticamente via email:

  • Via Web: => Scarica nymserver-pq-pubkey.bin (1.184 bytes raw)
  • Via Email: Invia una mail a key@nymserv-ng.virebent.art con qualsiasi oggetto. Il server risponderà allegando la chiave OpenPGP e il blocco esadecimale codificato della chiave ML-KEM-768.
  • Impronta crittografica SHA256:
    74c8ebca73fa8e7b9dd6329fc2f99580ef14cebb80ee7b3547fb0be550b7194f

2. Guida Passo-Passo per Principianti: Creazione del tuo Alias Post-Quantico

Passo 1: Genera la tua coppia di chiavi ML-KEM-768

Puoi utilizzare il binario da riga di comando nymserv-ctl fornito nei download ufficiali o qualsiasi libreria compatibile FIPS 203 (es. liboqs, Rust ml-kem, o Python): 

# Generazione chiave con nymserv-ctl
nymserv-ctl gen-keys --pq-only --out-dir ~/.nymserv-keys

Questo comando crea due file:

  • user-pq-pubkey.bin (Chiave pubblica di incapsulamento, 1.184 byte).
  • user-pq-secret.bin (Chiave privata di decapsulamento, da custodire gelosamente).

Passo 2: Prepara il blocco di registrazione Config

Componi il file di testo config-pq.txt inserendo la tua chiave pubblica in formato esadecimale (o base64) e il tuo Reply-Block: 

Config:
From: tuoalias-pq@nymserv-ng.virebent.art
PQ-Algorithm: ML-KEM-768
Public-Key-Hex:
[INSERISCI QUI LA STRINGA ESADECIMALE DELLA TUA user-pq-pubkey.bin]
Reply-Block:
::
Anon-To: la_tua_vera_email@provider-sicuro.org

Nym-Commands: +cryptrecv +pqsend

Passo 3: Incapsula e Cifra il Pacchetto per il Server

Utilizzando la chiave pubblica ML-KEM del server (nymserver-pq-pubkey.bin), incapsula una chiave simmetrica condivisa (32 byte) ed esegui la cifratura autenticata ChaCha20-Poly1305 del messaggio: 

# Cifratura automatica tramite tool nymserv
nymserv-ctl pq-encrypt --recipient-key nymserver-pq-pubkey.bin config-pq.txt > config-pq.bin.asc

Passo 4: Invia la richiesta a config@

Spedisci il pacchetto risultante all'indirizzo:

config@nymserv-ng.virebent.art

Il server decapsulerà il segreto, registrerà l'alias nel database ACID embedded redb e invierà una conferma cifrata Post-Quantica al tuo Reply-Block.

3. Ricezione Messaggi Post-Quantici (Inbound)

Quando qualcuno scrive a tuoalias-pq@nymserv-ng.virebent.art:

  1. Il server riceve l'email e genera una nuova chiave effimera ML-KEM-768 incapsulata con la tua chiave pubblica.
  2. Il payload del messaggio viene cifrato con ChaCha20-Poly1305.
  3. Il pacchetto cifrato Post-Quantico viene consegnato al tuo indirizzo di Reply-Block.
  4. Sul tuo computer decapsuli il segreto con la tua chiave privata user-pq-secret.bin e decifri il messaggio istantaneamente.

4. Invio di Email con Protezione Post-Quantica (Outbound via send@)

Per inviare email verso il clearnet dal tuo alias Post-Quantico:

  1. Firma il messaggio con la tua chiave Ed25519 o ML-DSA.
  2. Incapsula e cifra il pacchetto con la chiave pubblica ML-KEM del server.
  3. Invia il messaggio a: send@nymserv-ng.virebent.art.
  4. Il server verifica la firma, aggiunge il disclaimer X-Nym-Disclaimer e consegna la posta al destinatario finale.
